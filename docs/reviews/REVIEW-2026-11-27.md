# Review 2026-11-27

Scope: a full review of the app, the backend, the content and the repository history at `main`
(c812cba), as described in `docs/prompts/claude-tester.md`. Branch: `review/2026-11-27`.

What was run: `npm test` (84 tests passed before the fixes, 91 after) and `npm run build`
(`OK:`). A headless Chrome (puppeteer-core) ran at 390×844 against a local server. I tested the
backend only through the `.gs` files in a Node `vm` with the mocks from
`tests/backend-flow.test.js`. I never called the live `/exec`, Drive or Gemini.

## 1. Summary: the five most important findings

1. **One broken AI text stopped all syncing and all Drive backups, silently (fixed, F01).** If one
   content batch held a malformed text (a `null` item, or `paragraphs` that was not a list), the
   app threw on every sync. It never moved past that batch. The Drive backup runs after content,
   so backups stopped too. The only sign was a technical line on the You screen. On an iPhone,
   which can wipe home-screen app storage, that ends in lost progress.
2. **The app marked some wrong answers "Correct" (fixed in part, F04/F05).** The accent rule gave
   full marks to *hablo* for *habló* in the verb trainer, which is the present instead of the past.
   It also accepted the faulty sentence typed back unchanged in "find the mistake" exercises
   (u05, u10, u12). The verb trainer, the tables and the "find the mistake" case are fixed. Gap and
   translation exercises still accept *llego* for *llegó*, *esta* for *está*, *el* for *él* and
   similar pairs.
3. **The partner never got her own AI exercises or practice texts for a pool the owner had also
   asked for (fixed, F03).** The backend queue removed repeated requests across both learners. The
   batch was tagged for the first learner, so the second learner's app skipped it. Her app then
   waited 3 days before asking again.
4. **Anyone with a learner token can run Gemini with no limit (F02).** The "30 calls a night" limit
   resets on every run, and `nightly.run` has no rate limit, so repeated "Get new content now" taps
   or a leaked token can use up the free tier. If billing is ever turned on, this costs money.
5. **Correct Spanish is often marked wrong (F08, F10).** Reorder exercises accept only one word
   order, even where the time phrase can go first or last. Translations reject an optional subject
   pronoun (*Yo estoy cansado*) and feminine forms (*Cuando era niña*), although one learner is a
   woman. The code now accepts other orders listed in `a` for reorder exercises. The content still
   needs those alternatives added (section 3).

Counts: **1 critical, 5 high, 14 medium, 15 low** (35 findings). I fixed 5 of them in separate
commits, each with a test (section 6).

## 5. What I could not test, and why

- **A real iPhone, Safari and VoiceOver:** I used headless Chrome at 390×844 only. VoiceOver
  behaviour (F23) and the size of the iOS tap areas are inferred from the code and axe-core.
- **The live backend, Drive and Gemini:** not allowed by the brief. Backend findings come from the
